# Visual directions

Read this when a new page, site or visual identity has no design the user has picked.

The user chooses by looking. Copy alone in chat is never the draft of a new page.

## Steps

1. Name who lands on the page, what they came for and what it should make them do. Read the product's voice and design guidance.
2. Research the space. Capture eight to twelve real sites with screenshots, group them by what they lead with and note what each does well.
3. Decide the page's sections and write its words for that reader with `solo-write-copy` before any layout. Reuse a line from another page only when its reader is the same.
4. Build two or three directions as rendered pages, each from a different idea in the research. Use the same words and real images in each, so the choice is about look and identity.
5. Check each direction at phone and desktop widths and fix what the check finds before showing it.
6. Follow the shared visual-report guidance named in `solo-choose-approach`. Show the first screen of each direction at matched scale, link each full draft, and include the words, the research and one recommendation.
7. Once the drafts are visible, ask which direction to build. Follow `server/data/user-input.md` from the loaded plugin root. Build only the direction the user picks.

## Done when

The user can open every direction in place, and the page states the recommendation and the observation that would change it.
