# Resume a plan

Read this when the user asks to continue an existing plan.

## Steps

1. Locate the named plan, task record or repository plan folder. Ask which plan only when several plausible plans remain.
2. Confirm claimed progress using code, Git history and focused checks. A checked box is evidence to verify, not proof.
3. Preserve the goal, settled decisions and constraints. Start from the current diff and active failure. Keep the relevant spec, affected paths and last useful check result. Drop superseded attempts and verbose logs.
4. Explain steps that became unnecessary instead of silently dropping them.
5. Give the next step and its check. Keep a sound plan rather than rewriting it.
6. If the task uses a saved plan or Solo record, preserve the next action, outstanding decisions, checkout and head, changed paths, and check results there. Tie verification to the state it exercised and rerun it when that state changes.
7. Edit in place only for the same task. Do not replace unfinished plans that belong to other work.
