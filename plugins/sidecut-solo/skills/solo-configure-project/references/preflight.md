# Check setup before editing

Record the repository and ref you inspected, the settings and instruction paths you found, and the capabilities required for this task. Check the GitHub or host access the work actually needs. Report missing optional capabilities separately from blockers and continue with verified local evidence where possible.

For a setup audit, report observed state, evidence and proposed fixes. For an authorized edit, recheck settings and existing changes in the target checkout if it differs from the one inspected. Keep unattended changes reviewable in the repository diff. Report decisions that depend on the user's machine, account settings or permission.
